# VK MIX для Android

Музыкальный плеер для ВКонтакте · **by Den4iK**

Версия для компьютера живёт отдельно: [VK-MIX](https://github.com/Den4iKKing/VK-MIX).

## Скачать

**[Последняя версия](https://github.com/Den4iKKing/VK-MIX-android/releases/latest)** — файл `vk-mix-….apk`.

Нужен Android 8.0 или новее.

## Установка

Приложение распространяется APK-файлом, а не через магазин, поэтому при первой установке Android спросит разрешение ставить приложения из этого источника. Это обычный для такого случая вопрос.

**Google Play Защита покажет предупреждение** — «Play Защита никогда не проверяла это приложение». Это не про вирусы: Google так отвечает про любую программу, которой нет в его магазине. Можно нажать «Установить без проверки»; отправлять файл в Google не обязательно.

Проверить, что файл собран нами, можно по отпечатку подписи:

```
SHA-256: 7bbf369f81391c14e22c8c36e8a274fedd7121190c52d224e4f6e0caf9e08751
```

```
apksigner verify --print-certs vk-mix-0.9.0.apk
```

Все версии подписаны одним ключом — Android не даст установить поверх ничего чужого.

## Что умеет

- Вход через официальное приложение ВКонтакте, без пароля.
- Своя музыка, любимое, плейлисты, недавнее, поиск по библиотеке и по всему ВК.
- Главная со всеми подборками, жанрами и настроениями; страницы плейлистов и исполнителей.
- Плеер с очередью и текстом песни, управление из шторки, с экрана блокировки и кнопками гарнитуры.
- Скачивание на устройство. Без интернета приложение открывается на скачанном.
- «Сохранить как файл» — MP3 320 кбит/с, теми же байтами, что прислал ВК, с тегами и обложкой.
- Эквалайзер, скорость и тон, таймер сна.
- Добавить трек к себе, создать и изменить плейлист.

Приложение не держит телефон в сознании: за 25 минут погашенного экрана — ноль wakelock, ноль будильников, ноль фоновых задач. Служба воспроизведения завершается сама через пять минут после паузы.

## Обновления

Приложение раз в сутки проверяет, не вышла ли новая версия, и предлагает скачать. Загрузка не начинается без вашего нажатия, а установка — без вашего подтверждения.
